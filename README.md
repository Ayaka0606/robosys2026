# robosys2026

このリポジトリでは、ロボットシステム学の授業で作成したソフトウェアを公開しています。

## 概要

`plus` は、標準入力から受け取った数値を合計して、結果を表示するプログラムです。

整数と小数の計算に対応しています。また、計算できない文字や入力がない場合はエラーとして終了します。

## 使用方法

以下のコマンドで実行できます。

```bash
seq 5 | ./plus
```

実行結果

```text
15
```

標準入力から複数の数値を入力すると、その合計を表示します。

## エラー処理

- 計算できない文字が入力された場合は、終了ステータス1で終了します。
- 入力がない場合も、終了ステータス1で終了します。
- 正常に計算できた場合は、終了ステータス0で終了します。

## 動作環境

- Ubuntu
- Python 3
- Python 3.10、3.11、3.12、3.13、3.14で動作確認済み

## テスト

GitHub Actionsを使用して自動テストを行っています。

Python 3.10から3.14までの5つのバージョンでテストを実施し、すべて成功しています。
